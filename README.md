# 🔢 Digit Recognizer: The Gateway to Computer Vision

This repository contains my implementation of a handwritten digit recognition system using the famous **MNIST dataset**. This project serves as a cornerstone of my journey into Deep Learning and Image Processing.

## 🎯 Project Objective
The goal was to build and train a model capable of classifying images of handwritten digits (0-9) into their respective categories.

## 🧠 Technical Highlights
- **Architecture:** Convolutional Neural Networks (CNN).
- **Framework:** TensorFlow / Keras.
- **Concepts Applied:** - Data Normalization & Reshaping.
  - Convolutional & Pooling layers for feature extraction.
  - Dropout layers to prevent Overfitting.
  - Evaluation using Confusion Matrix and Accuracy curves.

## 📊 Performance
The model achieves an accuracy of **~99%** on the test set, demonstrating a solid understanding of how neural networks perceive visual data.

## 🚀 Why this matters?
Mastering the MNIST dataset was the first step that allowed me to transition into more complex 3D medical imaging projects like **StarBrain**.
